# PRODUCT_RESEARCH.md — Phase 1 : recherche produits (30 analysés → 14 retenus + 4 packs)

## Méthode & honnêteté des données
- **Douleur client / demande / concurrence / potentiel social** : analyse qualitative basée sur les catégories observables du marché e-commerce hiver français (places de marché, réseaux sociaux, saisonnalité Q4-Q1). Échelles : demande S/M/L, social 1-5, concurrence F(aible)/M/É(levée).
- **Coût fournisseur** : ⚠️ **FOURCHETTES D'ESTIMATION À VALIDER** (ordres de grandeur observables publiquement pour du B2B petit volume, Europe/Asie, hors transport & droits). **Aucun fournisseur réel n'est cité ni inventé** : le sourcing (devis, échantillons, DoC) est une action propriétaire (TASKS.md). La marge est calculée sur le milieu de fourchette, avant frais (Stripe ~1,5 % + 0,25 €, logistique, pub).
- **Réglementation** : textile = étiquetage composition (règl. UE 1007/2011) ; produits chimiques (sprays) = CLP ; électrique/électronique = DoC CE + DEEE + batterie le cas échéant ; bouillottes = normes d'usage (consignes) ; rien de « jouet » sauf mention < 3 ans.
- Critères d'exclusion appliqués : conformité invérifiable sans fournisseur réel (tout produit électrique/chauffant électronique, aérosols), casse/retours élevés, hors-saison, concurrence prix écrasante sans différenciation.

## Grille de prix retenue
- Entrée : 12,90 → 19,90 € (appel) · Cœur : 24,90 → 44,90 € · Premium maison : 49,90-59,90 € · Packs : 54,90-109,90 €.
- Panier moyen visé : 45-60 € (seuil livraison offerte 69 € incite aux packs — réglable via `SHIPPING_OPTIONS`).
- Marge brute moyenne catalogue : ~60-65 % **avant** frais (paiement, port, pub) — hypothèse de travail sur fourchettes estimées, à recalculer dès les devis réels.
